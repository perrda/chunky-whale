## What winning looks like

A Shopify-class merch store (FOMO21’s *structure*, our *voice*):

- Ghost-mannequin / white-well product photos
- Colour swatches that **change the product photo**
- Mega-nav: T-Shirts, Sweatshirts, Women, Hats, Kids, Swimwear, Drinkware, Jewelry, Posters, Stickers, Premium (stitched)
- Login + cart + checkout
- Light and dark mode
- Bitcoin-only merch: ₿ on almost every SKU. Memes, Satoshi, 21M, white paper, HODL, stack sats, charts
- Card + BTC/Lightning + USDC + USDT
- Printful-first dropship, Gelato scale, Printify jewelry/overflow
- Mid-price, fair markup (~2–2.5× landed print cost), VAT/tax honest
- Sizes XS–4XL plus women / youth / toddler / infant
- Size charts in US in / UK-EU cm / Asia
- Real shipping windows from Printful (fulfil 2–5 days + transit)
