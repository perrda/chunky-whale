# Pricing (plain English)

Mid-price. Fair markup. Not a luxury house, not a £9 Amazon tee.

## How a price is built

1. Printful blank + print/embroidery cost
2. Shipping the customer pays (shown at live checkout)
3. Tax (UK VAT 20% when live)
4. Our markup so the shop can exist: target **about 2–2.5×** the print cost, before shipping
